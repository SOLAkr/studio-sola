[폴더 구성]
  index.html        사이트 페이지
  app.js            사이트 동작(애니메이션, 팝업, 필터, 복사 등)
  data/portfolio.js 포트폴리오 내용 + 바꾼 글자·폰트  ← 업데이트할 때 바꾸는 파일
  editor.html       사이트 편집기(내 컴퓨터에서 여는 도우미)
  assets/           이미지, 영상, 폰트

[처음 배포하기]
  이 폴더 전체를 그대로 올리면 됩니다. 파일 이름·폴더 구조는 바꾸지 마세요.
  - 가장 쉬움: Netlify Drop (app.netlify.com/drop) 에 폴더를 끌어다 놓기
  - 추천(업데이트가 편함): GitHub 저장소에 올리고 Netlify / Vercel / Cloudflare Pages 에 연결
    → 이후 github.com 에서 data/portfolio.js 만 고치면 사이트가 자동으로 다시 배포됩니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[영상·채널 업데이트하기]  ※ 클로드 없이 직접
  1. editor.html 을 더블클릭해서 엽니다(크롬 또는 엣지 권장).
  2. 채널/카테고리를 펼쳐서 수정하거나 "＋ 새 항목", "＋ 영상 추가"를 누릅니다.
     - 영상은 유튜브 주소만 붙여넣으면 제목과 썸네일이 자동으로 채워집니다.
     - 맨 위 영상이 팝업의 대표 영상(크게 표시)입니다. "대표로" 버튼으로 바꿀 수 있어요.
     - 새 프로필 사진은 assets 폴더에 사진 파일을 넣고 "파일 고르기"로 선택하세요.
  3. 오른쪽 위 "저장"을 누릅니다.
     - 편집기를 열고 처음 저장할 때만 사이트 폴더(editor.html 이 들어 있는 폴더)를 고르고
       "수정 허용"을 눌러주세요. 그러면 data/portfolio.js 에 바로 덮어써집니다.
     - 그래서 편집기를 껐다 켜도 저장한 내용 그대로 열리고, 거기서 이어서 고치면 돼요.
     - 저장을 안 하고 창을 닫아도, 다음에 열면 고치던 내용을 자동으로 이어서 불러와요.
  4. 사이트 폴더를 다시 업로드합니다.
     (GitHub 연결 시: 저장소의 data/portfolio.js 를 새 파일로 교체 → 자동 배포)

  * 사파리·파이어폭스에서는 폴더에 바로 저장이 안 돼서, 저장을 누르면 portfolio.js 가
    내려받아집니다. 그 파일로 data/portfolio.js 를 직접 바꿔주세요.
  * "파일로 받기" 버튼은 portfolio.js 를 따로 내려받기만 해요(백업용).
  * data/portfolio.js 를 메모장/VS Code로 직접 고쳐도 됩니다. 파일 맨 위에 항목 설명이 있어요.

[글자·폰트 바꾸기]  editor.html 위쪽 탭
  정보       : 프로필(닉네임·나이 등), 사용 프로그램, 경력 숫자의 글자와 폰트
  경력 캡슐  : 흘러가는 경력 캡슐 추가·삭제·순서 바꾸기, 연도/이름/링크/역할, 캡슐 폰트
  가격표     : 가격 카드, 항목 목록, 환불 정책 글자와 폰트
  팝업 글자  : 포트폴리오 팝업 안 글자 모양(모든 팝업 공통)과 버튼 문구
  - 글자 칸에서 **굵게** 처럼 별표 두 개로 감싸면 굵은 글씨, 엔터는 줄바꿈입니다.
  - 폰트·크기·굵기·색을 비워두면 원래 디자인 그대로입니다. "되돌리기"로 언제든 원래대로.
  - 오른쪽 미리보기 칸에서 바뀐 모양을 바로 확인할 수 있어요.
  - 저장 방법은 위와 같아요: portfolio.js 저장 → data/portfolio.js 교체 → 다시 올리기.

[링크 미리보기(임베드)]
  링크를 디스코드·카톡 등에 올리면 제목 "STUDIO SOLA"와 assets/og-image.jpg 그림이 뜹니다.
  - 그림을 바꾸려면 assets/og-image.jpg 를 같은 이름의 다른 그림(가로 1200×675 권장)으로 교체.
  - 디스코드 등 일부 앱은 그림 주소가 전체 주소여야 해서, index.html 의
    "assets/og-image.jpg" 두 곳을 "https://내사이트주소/assets/og-image.jpg" 로 바꾸면 가장 확실합니다.
  - 이미 한 번 공유한 링크는 앱이 예전 미리보기를 기억해서 바로 안 바뀔 수 있어요.

[참고]
  - 팝업의 영상은 사이트 안에서 바로 재생됩니다. 영상 주인이 "퍼가기"를 막아둔 영상은
    재생 대신 "유튜브에서 보기"를 눌러야 합니다.
  - 썸네일·영상은 유튜브에서 불러오므로 인터넷 연결이 필요합니다.
  - JetBrains Mono, IBM Plex Sans KR, Unbounded 폰트는 Google Fonts에서 불러옵니다.
  - index.html 을 더블클릭해서 열어도 보이지만, 영상 재생과 히어로 스크롤은
    웹서버에 올렸을 때 가장 정확하게 동작합니다.
